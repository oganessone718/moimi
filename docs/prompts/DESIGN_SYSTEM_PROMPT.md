# 디자인 시스템 생성 프롬프트 (Claude Design용)

> 사용법: `docs/DESIGN_BRIEF.md`를 먼저 붙여넣고, 아래 프롬프트로 디자인 시스템을 생성한다.
> 결과로 나온 **CSS 변수 토큰 블록**은 나중에 코드(S0~)로 옮긴다.

```
너는 시니어 프로덕트 디자이너야. "모이미(moimi)"라는 서비스의 디자인 시스템을 만들어줘.
(첨부한 모이미 디자인 브리프를 기준으로 하고, 아래 지시를 우선 적용해.)

## 제품 한 줄
모이미 = "언제 + 어디서"를 한 번에 정하는, 가입 없이 카톡으로 쓰는 모임 약속 서비스.
한국어 서비스. 사용자는 대부분 카톡 링크를 통해 모바일로 들어온다.

## 톤 & 무드
캐주얼·플레이풀. 밝고 둥글고 친근하게. "약속 잡기의 귀찮음"을 가볍고 즐겁게 만든다.
딱딱한 엔터프라이즈 느낌 금지. 토스의 경쾌함 + 두들의 직관성 + 약간의 장난기.

## 만들 것: 디자인 시스템 스타일 가이드 (단일 페이지 아티팩트)
하나의 인터랙티브 페이지로, 아래 토큰과 컴포넌트를 모두 "쇼케이스" 형태로 보여줘.
모바일 우선(390px 기준)으로 설계하되, 페이지 자체는 데스크탑에서 보기 좋게 정리.
라이트 모드만 (다크는 나중). 한국어 라벨(Pretendard 가정).

### 1) 디자인 토큰 (값을 명시적으로 정의하고 화면에 표로 보여줘)
- 컬러:
  - Primary(따뜻하고 경쾌한 메인 1색 — 코랄/탠저린 계열 제안, 예 #FF7A59), 그 명암 단계(50~900)
  - 서브/보조색 1~2개(라벤더/스카이 계열)
  - 시맨틱: YES=초록 / MAYBE=노랑 / NO=회색 (신호등), success/warning/error/info
  - 중립: 배경(거의 화이트+옅은 웜그레이), 텍스트(강/중/약), 보더
  - 각 색은 HEX와 용도를 함께 표기
- 타이포: Pretendard 기준 타입 스케일 (Display/H1/H2/H3/Body/Caption), 크기(rem)·굵기·행간. 한글 가독성 우선.
- 스페이싱 스케일(4px 베이스: 4/8/12/16/24/32/48), radius(8/12/16/20/full), 그림자(sm/md/lg, 부드럽게), 모션(duration·easing 기본값)
- 토큰은 화면에 스와치/표로 보여주고, 하단에 **복사 가능한 CSS 변수(:root) 목록**으로도 정리해줘 (나중에 코드로 옮길 거야).

### 2) 컴포넌트 라이브러리 (각 컴포넌트를 상태별로 모두 보여줘)
- 버튼: Primary(채움)/Secondary(외곽)/Ghost × 크기 3종 × 상태(default/hover/pressed/disabled/loading). 모바일 하단 고정용 풀폭 버튼 포함.
- 투표 셀(3-state 토글): YES🟢 / MAYBE🟡 / NO⚪ — 색+아이콘+텍스트 병행(색만으로 구분 금지), 선택/비선택 상태
- 날짜 후보 카드, 시간대(가능 시간 범위) 선택 UI
- 장소 카드: 썸네일/이모지 · 이름 · 거리 · 좋아요 하트 · 댓글 수
- 닉네임 칩 / 아바타(이니셜+컬러), 참가자 목록
- PIN 입력(4~6칸)
- 공유 버튼(카카오 노란색 규격 고려) + 일반 공유/복사 버튼
- 상태 뱃지: 진행중 / 마감 / 확정
- 인풋/토글/체크박스, 토스트·스낵바, 스텝 인디케이터(위저드용)
- 빈 상태(empty state) 일러스트 1~2개 예시 (귀여운 톤)

### 3) 플레이풀 디테일
- 둥근 모서리, 부드러운 그림자, pill 칩, 이모지(📍🗓️🙌🎉) 활용
- 마이크로 인터랙션 의도를 주석/캡션으로 표기: 투표 탭 시 통통, 제출 시 🎉 컨페티, 1위 순위 이동 등

## 제약
- 색만으로 정보 전달 금지(색+아이콘+텍스트). 명도 대비 WCAG AA. 본문 16px, 최소 14px.
- 터치 타겟 44px+. 카톡 인앱 브라우저 고려(과한 풀스크린/스크롤 하이재킹 금지).

## 산출
한 페이지에 토큰 → 컴포넌트 → 상태 순으로 깔끔히 섹션화해서 보여주고,
끝에 CSS 변수 토큰 목록을 코드 블록으로 정리해줘.
이 디자인 시스템 위에 이후 실제 화면들을 얹을 거니까 재사용성과 일관성을 최우선으로.
```

## 참고
- 컬러는 "코랄/탠저린 제안"으로 열어둠 — 시안 받고 고르면 됨. 특정 색 원하면 Primary 부분만 교체.
- CSS 변수로 토큰을 받는 이유: 구현(S0~) 때 그대로 이식.
- 첫 결과가 약하면 "투표 셀만 다시", "컬러 팔레트 3시안" 식 부분 반복으로 품질 ↑.
